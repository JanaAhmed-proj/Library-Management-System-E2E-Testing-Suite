# Library System — Test Cases

Manual QA test case documentation for the **Library System** web application, covering Login, Add Book, View Books, Search Book, Borrow Book, Return Book, Delete Books, Stats, and Borrowed Books List functionality.

**Test Environment:** Google Chrome, Wi-Fi connection
**Application under test:** https://malakmohamed241.github.io/Librarysystem/ (Login) / https://malakmohamed241.github.io/ApiLibrarySystem1/ (core features)
**Default credentials:** `admin` / `1234`

## Summary

| Total | Pass | Fail |
|---|---|---|
| 37 | 35 | 2 |

Two failing cases are marked **[BUG]** in the Test ID column below:

- **TC-13** — the system allows adding a duplicate book (same title and author) instead of rejecting it.
- **TC-19** — an empty search field is silently treated as "no results" instead of showing a validation message.
